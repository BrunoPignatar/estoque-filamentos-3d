# Estoque de Filamentos 3D

Trabalho da disciplina Linguagem de Programação I – FIB.

## Tema

Cadastro e controle dos rolos de filamento para impressão 3D, com marca, material, cor, peso e preço.

## Tecnologias

- Node.js
- Express
- EJS
- MySQL (pacote mysql2)

## Como instalar e executar

```bash
git clone https://github.com/BrunoPignatar/estoque-filamentos-3d.git
cd estoque-filamentos-3d
npm install
```

1. Execute o arquivo `script.sql` no MySQL para criar o banco e a tabela.
2. Copie o arquivo `.env.example` para `.env` e preencha a senha do seu MySQL.
3. Inicie o servidor:

```bash
npm start
```

4. Abra http://localhost:3000 no navegador.
